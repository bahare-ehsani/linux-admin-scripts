# Linux Administration & DevOps Portfolio

A collection of practical Linux administration and DevOps projects focused on system management, automation, monitoring, and infrastructure operations.

Each project is maintained in its own public GitHub repository, with its own documentation, source code, and usage instructions.

## Projects

### 1. Server Stats

A Bash utility that displays essential Linux system and performance information, including CPU, memory, disk usage, processes, and logged-in users.

- **Project Repository:** [server-stats](https://github.com/bahare-ehsani/server-stats)
- **Project Page:** [roadmap.sh/server-stats](https://roadmap.sh/projects/server-stats)

### 2. Log Archive Tool

A Bash utility that creates compressed archives of log directories, verifies archive integrity, and maintains execution logs.

- **Project Repository:** [log-archive-tool](https://github.com/bahare-ehsani/log-archive-tool)
- **Project Page:** [roadmap.sh/log-archive](https://roadmap.sh/projects/log-archive)

### 3. Nginx Log Analyser

A Bash utility for analyzing Nginx access logs and summarizing the most frequent IP addresses, requested paths, HTTP status codes, and user agents.

- **Project Repository:** [nginx-log-analyser](https://github.com/bahare-ehsani/nginx-log-analyser)
- **Project Page:** [roadmap.sh/nginx-log-analyser](https://roadmap.sh/projects/nginx-log-analyser)

## Environment

- Linux
- Bash
- AlmaLinux 10.2 (development and testing environment)
- Git & GitHub

## Repository Structure

Each project is maintained in a separate repository to keep its source code, documentation, and development history independent.

This repository serves as the central index for the portfolio and will be updated as new projects are added.
